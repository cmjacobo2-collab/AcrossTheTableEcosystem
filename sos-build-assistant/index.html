Take a look

SOS Build Assistant, up close.

Who it’s for

For shops that build with partners.

Sign companies that use outside manufacturers or fabricators, and project managers who run installs.

Sign companies using outside shops

You send drawings out for bids instead of building in-house.

Project managers

You run production, delivery and install crews across many jobs.

Install coordinators

You need close-out paperwork filed the day the sign goes up.

The problem

Bids by email, jobs in spreadsheets.

Getting bids means emailing drawings to several shops and comparing quotes by hand. Once the job is awarded, production, delivery, install crews and close-out paperwork get tracked in spreadsheets and texts.

What it will do

From bid to close-out on one board.

01

Bids from the approved drawing

Send the approved drawing and specs to manufacturers for bids.

02

Compare and award

Compare bids side by side and award the job.

03

One board

Run each job from production and delivery through install and close-out.

04

One job record

Pick up the permit, inspections and close-out from SOS Permit Assistant, so the whole job lives in one record.
